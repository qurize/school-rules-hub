# 📘 ระเบียบโรงเรียน · School Rules Hub

เว็บไซต์กฎระเบียบโรงเรียนสำหรับทดสอบความรู้และเตือนความจำ ทำด้วย HTML / CSS / JavaScript ล้วน ไม่ต้องสร้าง Build

## 🌐 live Demo
หลังเปิดใช้งาน GitHub Pages: **https://qurize.github.io/school-rules-hub/**

## ✨ ฟีเจอร์
- **หน้าแรก** — ภาพรวมกฎ สถิติ ระบบเตือนความจำ และความก้าวหน้าล่าสุด
- **กฎระเบียบ** — ค้นหา แบ่งหมวดหมู่ และทำเครื่องหมายอ่านแล้ว
- **แบบทดสอบ** — เลือกหมวด/จำนวนข้อ/เวลา, เฉลยพร้อมคำอธิบาย, หน้าผลลัพธ์และทบทวนข้อผิด
- **หน้าครู** — เพิ่ม/แก้ไข/ลบกฎและคำถาม ดูสถิติการเรียนรู้
- **บันทึกข้อมูลในเครื่อง** — ใช้ `localStorage` (ไม่ต้องใช้ฐานข้อมูล)

## 🚀 Deploy ด้วย GitHub Pages
1. Push ไฟล์ขึ้น branch `main`
2. ไปที่ **Settings → Pages → Build and deployment**
3. ตั้ง **Source: Deploy from a branch → main → /root** แล้ว Save
4. เว็บจะพร้อมใช้งานที่ URL ด้านบนภายใน 1–2 นาที

> หมายเหตุ: ไฟล์ `.nojekyll` ช่วยให้ GitHub Pages เสิร์ฟไฟล์ static ตรง ๆ โดยไม่ผ่าน Jekyll

## 📂 โครงสร้าง
```
.
├── index.html   # โครงสร้างหน้าเว็บ
├── styles.css   # ออกแบบ UI / Responsive
├── app.js       # ตรรกะและการจัดการข้อมูล
└── .nojekyll    # ตั้งค่า GitHub Pages
```
